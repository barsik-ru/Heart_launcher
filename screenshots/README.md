# Скриншоты

В этой поставке не приложены новые скриншоты работающего Electron runtime: установка npm-зависимостей завершилась по тайм-ауту, поэтому Electron и React-приложение не были запущены. Скриншот из вложений пользователя является визуальным ориентиром и не выдаётся за новый screenshot приложения.

После установки зависимостей:

```bash
npm install
npm run dev
```

Сделать фактические снимки Login, Home, News, Modpack, Profile, Settings и Installation.
